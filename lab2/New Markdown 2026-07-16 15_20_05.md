**Medallion Architecture** – a way of organizing data by processing it in multiple stages:
- **Bronze (raw data)** – data is ingested into the system without modifications, the original format is preserved, and metadata such as the ingestion date or source file name can be added.
- **Silver (cleaned data)** – duplicates are removed, data types are corrected, and basic data transformations are performed.
- **Gold (business-ready data)** – data is prepared for dashboards, reports, machine learning models, and business analytics.

**Managed Identity vs. Service Principal** – both are authentication mechanisms used by applications in Azure.
- **Service Principal** – a dedicated application identity that works across different environments and provides full control. However, the client secret must be securely stored, rotated periodically, and may eventually expire.
- **Managed Identity** – Azure manages the application's identity automatically. There is no client secret, password, or secret rotation required, as Azure issues access tokens on behalf of the application. This results in simpler and more secure code. It requires proper configuration, works only within Azure services, and is considered the more modern approach.
